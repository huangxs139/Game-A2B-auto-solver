# FEAT0002 — Implement A=B Executor

## Goal

Implement the shared A=B Executor using the accepted machine-readable Rules.

## Scope

The feature contains three closely related capabilities.

### Instruction Semantics

Implement the execution behavior required by every instruction represented in the accepted Rules.

Rules operation identifiers, parameters, and Executor implementations must be correctly associated.

### Execution Workflow

Implement complete A=B program execution, including:

* parsing/handling serialized A=B code as required;
* identifying the first currently executable instruction;
* executing it correctly;
* restarting from the first instruction after execution;
* terminating when a complete scan finds no executable instruction;
* detecting or safely handling invalid nonterminating execution;
* returning structured execution results.

The conceptual normal interface is:

```text
execute(input, code_snippet) -> ExecutionResult
```

### Debug Observation

Executor Debug operation must be capable of collecting and dumping useful execution observations.

Debug instrumentation must not intentionally alter normal A=B execution semantics or results.

The exact observation schema is implementation-defined.

## Out of Scope

* solving algorithms;
* Solver workflow;
* Manager orchestration;
* full-puzzle candidate-validation workflow;
* owner real-game validation.

## Verification

Unit tests must verify at least:

1. each implemented A=B instruction behaves according to the accepted Rules;
2. complete multi-line code snippets follow the required A=B execution workflow;
3. normal termination works correctly;
4. applicable invalid looping/nontermination behavior is detected or safely handled;
5. Debug observation/dump data can be collected;
6. Debug instrumentation does not change expected execution behavior.

Codex must run applicable tests and perform self-review before requesting owner review.

## Acceptance

FEAT0002 is ready for owner review when:

* required Executor behavior is implemented;
* applicable tests pass;
* Codex self-review finds no unresolved issue within feature scope.

Final feature acceptance belongs to the owner.
