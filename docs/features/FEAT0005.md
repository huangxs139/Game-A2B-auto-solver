# FEAT0005 — Solver Algorithms — Chapters 4–6

## Goal

Implement actual solving capability for A=B Chapters 4–6 using the Solver Framework.

## Scope

Implement the solving algorithms required to automatically produce locally valid candidates for every project puzzle in Chapters 4–6.

Codex may freely determine the internal algorithmic design.

The implementation may:

* reuse algorithms developed for earlier chapters;
* extend or replace those algorithms;
* use different algorithms by chapter;
* combine multiple strategies;
* use heuristics, search, synthesis, constraint solving, or other suitable techniques;
* introduce puzzle-specific methods where useful.

No requirement exists that one technique solve all chapters or generalize beyond the puzzles for which it is useful.

Implementation-level algorithm evolution remains internal to this feature rather than requiring separate feature decomposition.

Any new third-party dependency requires owner approval before introduction.

## Constraints

Candidates must comply with the accepted Rules.

Search heuristics must not be promoted into false A=B semantic restrictions.

A final candidate must satisfy the local-validity requirements in `REQUIREMENTS.md`.

## Verification

For every project puzzle in Chapters 4–6, Solver must automatically produce a final serialized candidate that:

* satisfies `min_lines`;
* passes the complete exported input/output dataset through the project execution system.

Domain-level solving results are the primary verification evidence.

Applicable low-cost unit or regression tests should still be used for algorithm-supporting components where useful.

Codex must self-review the implementation and solving results before owner review.

## Acceptance

FEAT0005 is ready for owner review when all project puzzles in Chapters 4–6 have locally valid automatically produced candidates.

Final feature acceptance belongs to the owner. Real-game validation governs final puzzle acceptance and project completion separately under `REQUIREMENTS.md`.

Acceptance of FEAT0005 does not constitute final project completion.
