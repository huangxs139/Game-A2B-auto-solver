# Experimental-A-equal-B-auto-solver
 An experimental AI agent project that automates puzzle-solving in the programming game "A=B". This repository serves as a proof-of-concept for AI agent architecture and collaboration patterns, leveraging Yi-lightning API to create an intelligent solver for the game's unique "A=B" replacement-based programming challenges.  The project demonstrates practical applications of AI agents in gaming automation while establishing a foundation for future AI agent development. "A=B" is an indie programming puzzle game on Steam that challenges players with a single instruction (A=B) to solve various computational problems, making it an ideal testbed for AI problem-solving capabilities.  Keywords: AI Agent, Yi-lightning API, Game Automation, Programming Puzzles, Experimental Architecture
